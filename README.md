# ICE2
A low-level, high-tolerance, high-fault-resistance, exotic, robust, and powerful interpreted programming language.

This repository actually contains a VM that interprets ICE code (looks like binary code) and LICE (Lexical ICE) more easy to use and left can translate into ICE code.
